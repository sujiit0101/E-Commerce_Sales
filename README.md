# E-Commerce Sales Dashboard 📊

## 1. Project Title
**E-Commerce Sales Analysis Dashboard using Power BI**

## 2. Short Description
I created this dashboard using Power BI to analyze e-commerce sales data and understand business performance. It shows total sales, gross profit, profit margin, units sold, and total orders.

The dashboard also helps to compare sales across different platforms, product categories, countries, and months. I used charts, KPIs, and filters to make the data easy to understand.

## 3. Tech Stack
- **Power BI** – To create the interactive dashboard and visualizations
- **Power Query** – To clean and transform the data
- **DAX** – To calculate sales, profit, and other KPIs
- **Microsoft Excel / CSV** – For handling the dataset

## 4. Data Source
The project uses e-commerce sales data containing information about revenue, gross profit, product categories, platforms, customer countries, monthly sales, units sold, and orders.

## 5. Features

- **KPI Cards:** Display total sales, gross profit, profit margin, units sold, and total orders.
- **Global Sales Distribution:** Shows sales distribution across different countries and regions.
- **Sales by Category:** Compares sales across product categories.
- **Sales and Profit by Platform:** Compares performance across Shopify, eBay, and Amazon.
- **Monthly Sales and Profit Trend:** Helps track changes in sales and profit over time.
- **Top 10 Products:** Highlights the products generating the highest sales.
- **Country Performance:** Compares orders, revenue, and profit across countries.
- **Interactive Filters:** Allows users to filter the dashboard by year/month, platform, and customer country.
